📖 使用说明

目标

看饮片图 → 认出药名 → 背下药性 / 功效 / 用法用量 / 注意事项。

模式

点左上角「☰」选模式：随机抽查（错题加权）、顺序、错题本、分类、快刷、模拟、纯图（只出图、点图显示答案）。

操作

图片左右「‹ ›」翻题；答案卡输入药名核对，或点「显示答案」；答错自动进错题池（70% 优先抽）。

快捷键

空格 / N / → 下一张；← 上一张；R 显示答案。

进度

存在本浏览器，换设备不互通。

突击建议

快刷过一遍 → 随机抽查 → 错题本攻 → 考前模拟。

易混对比（孪生药）
附 · 十八反 / 十九畏

“十八反”

本草明言十八反，半蒌贝蔹芨攻乌。藻戟遂芫俱战草，诸参辛芍叛藜芦。（甘草反甘遂、大戟、芫花、海藻；乌头〔川乌、草乌、附子〕反贝母〔川贝母、浙贝母〕、瓜蒌、半夏、白蔹、白及；藜芦反人参、丹参、沙参、玄参、苦参、细辛、芍药。）

“十九畏”

硫磺畏朴硝，水银畏砒霜，狼毒畏密陀僧，巴豆畏牵牛，丁香畏郁金，川乌、草乌畏犀角，牙硝畏三棱，官桂畏石脂，人参畏五灵脂。
